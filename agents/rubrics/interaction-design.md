# Rubric: interaction design

Original: https://61040.github.io/fa26/rubrics/interaction-design/

Evaluate the running app for the journey being claimed. Say which journey you scored.

## Qualities

Understandable: names and controls teach the concepts, not the module list. Directed toward the task: the user does not have to walk the concept graph. Informative: state, success, progress, and why something is disabled. Consistent. Forgiving: errors are recoverable and say what to do next.

## Pitfalls

One page per concept, or one button per action. Hidden prerequisites. An unexplained “Done.” Only the happy path.

## Levels

- **Deficient** — important tasks cannot be completed, or the UI lies
- **Emergent** — possible if you guess, or if someone gives a tour
- **Competent** — main tasks work without a designer present; mistakes are correctable; some awkwardness is fine
- **Expert** — a confusing task feels straightforward because the UI absorbed the difficulty
