# Rubric: reflective practice

Original: https://61040.github.io/fa26/rubrics/reflective-practice/

Reflections for this course live in each student’s private repo. Do not add a reflection file to the team repo. Where that rule comes from is `../assignment.md`.

## Qualities

Focus. Grounding in specific events. Depth, not a tally of tasks. Self-awareness. Integration, so it could be spoken as one piece. Forward-looking actions.

Negative conclusions are welcome. A reflection generated only from the product, with no personal events, is usually impersonal.

## Pitfalls

Impersonal. Disconnected from the activity. Rambling. Shallow detail with no lesson.

## Levels

- **Deficient** — vague, no concrete lessons
- **Emergent** — observations and some self-awareness, no useful lessons
- **Competent** — a coherent personal account with lessons
- **Expert** — insight that will change the next project, and that enriched the work itself
