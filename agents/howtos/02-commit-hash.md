# How to submit a git commit hash

Original: https://61040.github.io/fa26/guides/hash/

Staff grade a **commit URL**, not whatever the branch tip is later.

1. On GitHub, on the branch to submit, open the commit from its short hash.
2. Choose **Browse files** so the URL is the repository at that commit.
3. Copy the full address-bar URL, including the hash.
4. Paste that URL into Commons.

The team repo and each person’s private repo need their own URL when both are required.

## When someone needs a hash

Do not create a commit unless asked. After the commit they want is pushed, `git rev-parse HEAD` is the hash. The submission still wants the GitHub browse-files URL, not the hash alone.
