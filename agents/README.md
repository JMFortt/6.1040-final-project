# Handbook

Shared notes for the team and for coding agents. Course pages win when a note disagrees with them; fix the note.

Three kinds of material live here. Keep them apart.

| Kind | Where | What belongs | What does not |
| --- | --- | --- | --- |
| Principles | [`readings/`](readings/INDEX.md), [`modularity.md`](modularity.md), [`rubrics/`](rubrics/INDEX.md) | What a concept is, how to specify and split one, how that kind of work is scored | Redraw’s features, deadlines, task owners |
| Stack | [`howtos/`](howtos/INDEX.md), [`generating-code.md`](generating-code.md) | Bun, MongoDB, the sync engine, Vue, and how a course-format spec becomes code | What Redraw should do |
| This project | [`AGENTS.md`](AGENTS.md), [`project.md`](project.md), [`assignment.md`](assignment.md), [`working-notes.md`](working-notes.md) | Standing rules, design goals, final-project process, open questions | A second copy of a deliverable |

## Read first

1. [`AGENTS.md`](AGENTS.md) — rules for working in this repo
2. [`project.md`](project.md) — what Redraw is for
3. The matching note in [`readings/`](readings/INDEX.md) or [`rubrics/`](rubrics/INDEX.md)
4. For implementation: [`modularity.md`](modularity.md), [`generating-code.md`](generating-code.md), [`howtos/INDEX.md`](howtos/INDEX.md)
5. [`assignment.md`](assignment.md) when the task is a deliverable, a mentor meeting, or a submission
6. [`working-notes.md`](working-notes.md) for questions that are still open

`deliverables/` and `mentor-meetings/` are the team’s assignments. Read them. Do not edit them unless a teammate explicitly asks.

## Where a new note goes

- A rule for the rest of the project → `AGENTS.md`
- A settled fact about Redraw → `project.md`
- An unsettled design or stack question → `working-notes.md`
- A course idea → `readings/`
- A command or platform step → `howtos/`
- How a spec becomes code, or how concepts stay independent → `generating-code.md` or `modularity.md`
- How work is graded → `rubrics/`
- A deadline, meeting format, or submission step → `assignment.md`

Write short imperative sentences. Link a course page instead of pasting it.
