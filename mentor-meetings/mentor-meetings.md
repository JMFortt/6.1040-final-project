### Project summary

The bad situation we've identified here is that artists want to get better at fundamental skills in art, but lack motivation and structure. Existing apps either offer little motivation to commit to practice (which can be grueling and boring), or they lack focus to actually practice those fundamental skills.

We intend to build an app that:

- Has a list of art fundamentals and a measure showing visually how much each has been practiced

- Lets users pick a randomized reference specific to different fundamentals and draw on the site with simple tools

- Lets users post their finished image for others to analyze when viewing the same reference image

- Keeps a streak counter to encourage daily practice

### Issues

- Deciding currently whether to include photo upload options for non-tablet users.

- Need to decide where to pull reference images from concretely.

- Need to decide if we want AI to play a role in categorizing images.
